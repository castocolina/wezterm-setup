<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| installer -> user scenes dir | the seeder writes into a user-owned dir that may already hold user-edited recipes |
| repo seed files -> installed recipes | in-repo seed bytes are copied to the user's config tree |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-05 | Tampering (data loss) | seeder clobbering user-edited recipes | mitigate | copy-if-absent: `plan_seed` marks existing dests "keep"; `run()` RE-CHECKS dest absence at write time (TOCTOU guard) and never overwrites. The `cp -R` clobber path is closed by keeping seeds OUTSIDE `config/wezterm-setup/` (D-06). Proven by the edit-survives-reinstall test. |
| T-05-06 | Tampering (shell injection) | paths passed to `io.popen`/copy in run() | mitigate | every dir/path passed to `io.popen` goes through `install_state.shquote` (CR-02 single-quote escaper) — a scenes-dir path with a metacharacter cannot break out. |
| T-05-07 | Elevation of Privilege | install writes | accept | all writes target user paths (`~/.config/...`), sudo-free (T-04-04 precedent); no privileged write surface. |
</threat_model>
