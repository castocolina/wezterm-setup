The prior version of this plan assumed `mux.cli_list` exposed only `pane_id`/`tab_id`/`cwd`/
`user_vars`, forcing brittle proxy assertions for TogglePaneZoomState and leaving "active tab"
observation entirely undefined; it fired only ONE of the four required `ActivatePaneDirection`
variants (contradicting the PRD's own must-have); it assumed a `fire_chords` schema that
conflicted with Plan 01's; and its `<verify>` block grepped the TEST FILE's source text for action
names instead of the LIVE RUN's output. Empirical confirmation during planning
(`wezterm cli list --format json` on this exact box) shows `is_active`, `is_zoomed`, and
`size.{rows,cols}` ARE genuinely present in this build's output — so this revision extends
`mux.cli_list` to surface them and rewrites every affected case to assert against the REAL field,
never a proxy for something that turns out to be directly observable. All four
