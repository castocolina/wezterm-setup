**stdout/stderr capture for `run()`-level assertions** (`pane_test.lua:55-63`) — reuse to
assert section ordering / red-on-TTY / no-color-in-json end-to-end:
```lua
local function capture(fn)
  local out, err = {}, {}
  local real_write, real_stderr = io.write, io.stderr
  io.write = function(...) for _, v in ipairs({ ... }) do out[#out + 1] = tostring(v) end end
  io.stderr = { write = function(_self, ...) for _, v in ipairs({ ... }) do err[#err + 1] = tostring(v) end end }
  local code = fn()
  io.write, io.stderr = real_write, real_stderr
  return code, table.concat(out), table.concat(err)
end
```

### `config/wezterm-setup/keybindings.lua` (config — modify in place, D-10)

**Analog:** itself. The already-working SINGLE-entry pane rows are the target form; the
clear/close-tab DUAL twins are what gets normalized.

**Twins to collapse** — clear (`keybindings.lua:79-81`) and close-tab (`:85,:91-92`):
```lua
{ key = mapped("k"), mods = M.super_mod,   action = { type = "ClearScreenAndScrollback" } },
{ key = mapped("k"), mods = "CTRL|SHIFT",  action = { type = "ClearScreenAndScrollback" } },
{ key = mapped("K"), mods = "CTRL|SHIFT",  action = { type = "ClearScreenAndScrollback" } },  -- DROP twin
...
{ key = mapped("w"), mods = "CTRL|SHIFT",  action = { type = "CloseCurrentTab", confirm = false } },
{ key = mapped("W"), mods = "CTRL|SHIFT",  action = { type = "CloseCurrentTab", confirm = false } },  -- DROP twin
```

**Canonical single-entry form to mirror** — the close-pane / pane family already does
exactly D-10 (`keybindings.lua:100-103`), single lowercase base + explicit SHIFT in mods:
```lua
{ key = mapped("x"), mods = "ALT|SHIFT", action = { type = "CloseCurrentPane", confirm = false } },
{ key = mapped("z"), mods = "ALT|SHIFT", action = { type = "TogglePaneZoomState" } },
```
D-10 primary form: keep one `mapped("k")`/`mapped("w")` `CTRL|SHIFT` entry, drop the upper
twin. Fallback (probe-driven only): one `mapped("K")` `CTRL|SHIFT` entry — still ONE entry.

**Lockstep guard (RESEARCH Pitfall 3):** D-10 changes only `key`/`mods`, never
`action.type`, so `init.lua resolve_action` stays untouched — but verify no type drifts
(the switch `error()`s on an unknown type → config-load crash). Behavior-affecting →
gate behind the D-09 live firing probe (`.tmp/h<NN>-*/`); the installed config is a COPY,
so `cp`/re-install before the live test (Pitfall 4). `M.disabled_defaults` (`:135-150`)
and `M.key_map_preference = "Mapped"` (`:154`) must stay consistent.
