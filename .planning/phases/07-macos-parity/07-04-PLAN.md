<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub release (network) → local install | The published `wez` binary crosses into local execution via curl\|bash. |
| macOS Gatekeeper → first launch | The OS gates execution of a downloaded/self-built Mach-O. |
| tag push → public release | A `v*` tag triggers a public, hard-to-unpublish stable release. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-13 | Tampering | MITM'd / wrong `wez` download | mitigate | Per-asset SHA-256 verified BEFORE chmod +x (build.sh download_release, portable shasum); a mismatch aborts non-zero — confirmed live in Task 2. |
| T-07-14 | Tampering | premature/unnecessary quarantine strip | mitigate | D-07 verify-then-decide: probe first; strip added ONLY if Gatekeeper actually blocks; default is no install.sh change (Pitfall 5). |
| T-07-15 | DoS | unsigned arm64 killed → user weakens Gatekeeper | mitigate | Ad-hoc codesign at build (Plan 03) clears the SIGKILL so users never disable Gatekeeper; arm64 evidence via the macos-14 smoke. |
| T-07-16 | Tampering | curl\|bash partial-stream execution | mitigate | install.sh invokes main() on the literal last line (existing) so a truncated stream can't run a half-command. |
| T-07-17 | Repudiation | premature public stable release | mitigate | First `v*` tag auto-push is gated on dry-run-green AND E2E-green (D-10) — NOT pushed on any red signal; the nightly channel auto-publishes meanwhile, so no stable tag is cut until both signals are green (no human gate; the green-gate is the safety rail). |
</threat_model>
