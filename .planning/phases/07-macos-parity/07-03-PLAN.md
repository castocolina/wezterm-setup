## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Official wez/wezterm GitHub release download → local extraction | the SAME trust boundary install_linux() already crosses today (unchanged host, unchanged integrity-before-extraction discipline); this plan extends it to the macOS `.zip` asset |
| Extracted WezTerm.app bundle → symlinked onto the user's `${BIN_DIR}` | a malicious or corrupted bundle could place an unexpected executable that gets symlinked onto PATH |

| T-07-06 | Tampering | downloaded WezTerm-macos-\<tag\>.zip | high | mitigate | PK-zip-magic + size-floor integrity gate BEFORE any extraction, plus an explicit `unzip -Z1` member-safety scan rejecting absolute/`..` paths — both run strictly before `ditto -x -k`, mirroring install_linux()'s existing pre-extraction discipline (T-02-01/T-02-02) |
