## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-07-07 | Elevation of Privilege | `.app` placement path | mitigate | `${HOME}/Applications` only, never `/Applications`, never sudo, never `hdiutil` (D-05); enforced by acceptance greps. |
| T-07-08 | Tampering | premature quarantine strip | accept (deferred to D-07/Plan 04) | install_macos does NOT mutate `com.apple.quarantine`; the verify-then-decide call is Plan 04's empirical step. |
