<threat_model>
## Trust Boundaries

This is a decisions-and-evidence phase: it produces prototype scripts that run locally against
the user's own already-running WezTerm session and a committed Markdown decision record. There
is no shipped code, no network exposure, no authentication surface, and no untrusted-input
handling — the prototypes are deleted from `.tmp/` after promotion (R5) and never integrate into
`config/`, `cli/`, or any installed artifact in this phase.

</threat_model>
