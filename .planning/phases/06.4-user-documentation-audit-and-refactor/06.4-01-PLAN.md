<objective>
Build the durable, zero-config automated drift-check test that is the verification backbone
for the whole phase (D-08/D-09). It enumerates the documented surface (commands, flags,
keybinding chords, scene fields) from the project's docs and asserts each item EXISTS in the
real source-of-truth modules. Direction is documented → exists ONLY (D-09): a doc that names a
nonexistent command/flag/keybinding/scene-field FAILS the suite; it does NOT enforce
shipped → documented.

Landing this FIRST gives every downstream doc plan (02/03/04) a machine check it can run after
editing prose, so "verify before declaring done" is satisfied by a test, not by hand-waving.

Purpose: a single, always-current gate that makes documentation drift a build failure.
Output: `tests/docs_drift_test.lua`, auto-discovered by `tools/run-tests.sh` / `make test`.
</objective>
