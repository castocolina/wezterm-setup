  once that `--help` + completion is the exhaustive reference.

  with a pointer to `wez keys` (and `--platform`/`--json`).

  symptoms, the exact `wezterm.lua` remediation, and the timestamped-backup recovery path — carried
  into `docs/troubleshooting.md` with the migration framing dropped.
- **Trust model (T-06.4-03):** the install trust model is carried forward unchanged — HTTPS =
  transport only, inspect-before-run, `WEZ_REF` pinning, SHA-256-before-chmod. No weakening.
- **No secrets in examples (T-06.4-04):** all examples use generic dirs/commands/placeholder tags.
