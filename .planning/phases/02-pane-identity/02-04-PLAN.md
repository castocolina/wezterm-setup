<objective>
Add `wez pane title "<text>"` to the existing `cli/commands/pane.lua` module (created in 02-03) and register the `title` subcommand under `pane` in `cli/spec.lua`. The title accepts freeform text + emoji AND an icon-name shortcut map (D-04): if the first token is a known icon name it is replaced by its glyph and the remainder is the title; otherwise the whole input is the title. The resolved title is written via OSC 1337 `SetUserVar=WEZTERM_TAB_TITLE` (reusing 02-03's `M.build_osc1337` and write sink), which 02-02's `format-tab-title` handler renders, overriding the tab's displayed title while the pane is focused. An empty string or `reset` clears the var.

Purpose: completes the pane-identity surface (PANE-03) — pane-specific titles in the tab bar — reusing the OSC builder and target/sink seam established in 02-03 so a future `--pane-id` sink (Phase 4) works for titles too.

Output: `cli/commands/pane.lua` (extended: `M.ICONS`, `M.resolve_title`, title branch in `M.run`), `cli/spec.lua` (register `pane title`), `cli/commands/pane_test.lua` (extended fixtures).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI argv -> pane.lua | User-supplied title words cross from untrusted shell input into OSC 1337 construction |
| pane.lua -> terminal stdout | The OSC 1337 sequence is written to the pane's tty and interpreted by WezTerm |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04-01 | Tampering | M.build_osc1337 (title payload) | mitigate | the title text is base64-encoded (reusing 02-03's encoder) before insertion into the OSC 1337 SetUserVar sequence; base64 output is restricted to `[A-Za-z0-9+/=]`, so a title containing raw `\27`/BEL/ST cannot terminate the OSC or inject a second escape sequence |
| T-02-04-02 | Tampering | M.resolve_title | accept | resolve_title only concatenates/looks-up tokens; it performs no eval and emits no escapes itself — all emission goes through the base64-guarded builder |
| T-02-04-03 | Denial of Service | format-tab-title render (downstream) | accept | an extremely long title is bounded at render time by 02-02's `max_width` truncation; the CLI does not loop over title length beyond a single concat |
</threat_model>
