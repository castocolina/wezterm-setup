# Phase 06.2 Plan 03: Render Layer (format-tab-title) Summary

The `format-tab-title` render handler now agrees with the split carriers and the explicit icon attribute: it composes the icon left of a literal title (D-04), resolves the tab accent by the D-08 three-step precedence (tab color > followed pane color > neutral), self-labels empty-title tabs by their launch-dir basename (D-11/D-13), and the legacy `<color>:<title>` parser is gone from the render path (D-05/D-06).

## What Was Built

- **`M.compose_label_text(icon, title)`** — icon left of title, single space; icon-only when no title, title-only when no icon (D-04).
- **`M.basename(path)`** — pure last-segment basename, a deliberate lockstep duplicate of `cli/lib/title.lua` (the standalone config bundle has no `cli/lib` require — the one justified reuse exception, lockstep-commented).
- **`M.title_with_fallback(title, icon, launch_dir)`** — non-empty title wins (D-11); empty title falls back to the basename, composed with the icon when present (D-13).
- **`M.resolve_accent(uv)`** — D-08 three-step precedence over the active pane user vars: (1) the tab's own `WEZTERM_TAB_COLOR` always wins; (2) else `WEZTERM_TAB_FOLLOW_PANE == "1"` + `WEZTERM_PANE_COLOR` follows the pane accent (opt-in, default OFF, D-09); (3) else neutral `M.DEFAULT_PROFILE` (D-10). `resolve_profile` is unchanged, preserving the malformed/over-long tamper fallback (T-06.2-06).
- **Handler rewire** — reads `WEZTERM_TAB_ICON`, sources `launch_dir` from `active_pane.current_working_dir` (Url-table-aware) then the pane title, composes the displayed text via `title_with_fallback`, and resolves the accent via `resolve_accent`.
- **Removed** — `M.parse_tab_title` and the `migratedTitle` handler branch; a stored `"cyan:api"` now renders verbatim.
- **Tests** — `format-tab-title_test.lua` extended with compose/basename/fallback unit checks, four `resolve_accent` precedence cases, and handler-e2e checks for icon+title, empty-title basename fallback, icon+basename, literal legacy rendering, and follow-on/off accent painting.
