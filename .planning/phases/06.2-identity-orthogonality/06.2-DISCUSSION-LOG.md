## Icon CLI surface

### How to set an icon on the CLI

| Option | Description | Selected |
|--------|-------------|----------|
| Dedicated subcommand | `wez tab icon`/`wez pane icon`, mirroring color/title | |
| Flag on color/title | `--icon` option on existing commands | |
| Both subcommand + flag | Standalone `icon` subcommand AND an `--icon` convenience flag | ✓ |

**User's choice:** Both subcommand + flag.

### What icon inputs to accept

| Option | Description | Selected |
|--------|-------------|----------|
| Named map + any emoji | Named ICONS key OR any literal glyph/emoji | ✓ |
| Named map only | Only curated ICONS names; arbitrary glyphs rejected | |
| Any string, no map | Drop the named map entirely | |

**User's choice:** Named map + any emoji.

### Where the `--icon` flag lives

| Option | Description | Selected |
|--------|-------------|----------|
| On color + title both | `--icon` on color and title subcommands | |
| On title only | `--icon` only on the title subcommands | ✓ |
| On color only | `--icon` only on color | |

**User's choice:** On title only.

### Icon + title render order

| Option | Description | Selected |
|--------|-------------|----------|
| Icon left of title | `💚 api` — icon prefixes literal title | ✓ |
| Icon only when no title | Icon replaces title text | |
| Icon right of title | `api 💚` | |

**User's choice:** Icon left of title.

### Doctor gate for legacy usage

| Option | Description | Selected |
|--------|-------------|----------|

migration tracking. A clean reinstall or config edit is an acceptable reset (echoes
6.1 D-10). User confirmed this reconciliation implicitly by moving on.
