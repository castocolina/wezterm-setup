# Phase 06.2 Plan 05: Seed refresh + live verification Summary

The shipped seed recipes now use the explicit icon attribute, and every Phase 6.2 behavior
was verified at the byte/render layer (headless) AND in a real WezTerm GUI window — which
surfaced and fixed one latent rendering defect.

  identity via the explicit `icon` key (tab `icon=build/ai/docker`; per-pane `edit/shell/git`,

  real WezTerm window on the 6.2 repo config and confirmed the actual tab-bar paint:
  - `wez tab icon node` + `wez pane title api` → **`💚 api`** (icon left of literal title, D-04).
  - Color split, follow-pane precedence, and cwd fallback confirmed via the headless render of
    the real `format-tab-title` callback (accent bg `#1e3a5f` blue tab-wins, `#5f1e1e` follow→pane,
    `#333333` neutral) and OSC decode of the CLI emits.

## Defect found + fixed (live repro value)

The first GUI capture showed `wez tab title api` rendering as `bash` (the pane process title),
not `api`: the `format-tab-title` handler never read `tab.tab_title`. Fixed in
`config/wezterm-setup/format-tab-title.lua` (`94b6258`) by inserting `tab.tab_title` into the
title precedence below the pane user var and above the process title — additive, no existing
behavior changed. Covered by RED→GREEN render tests 16a/16b/16c (`e02ca56` → `94b6258`) and
re-verified live (`🦀 api` renders).
