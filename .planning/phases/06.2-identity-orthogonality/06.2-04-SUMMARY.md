# Phase 06.2 Plan 04: Scene/Recipe Schema (icon + follow_pane_color + per-pane carriers) Summary

The scene/recipe model now carries the same identity orthogonality the standalone CLI got in Plan 02: `--pane` accepts an `icon=` segment, recipes carry a tab-level `icon` + per-`[[pane]]` `icon` + a tab-level `follow_pane_color` opt-in, and the scene command emits the split per-pane carriers (`WEZTERM_TAB_ICON`, `WEZTERM_PANE_COLOR`) plus the locked `WEZTERM_TAB_FOLLOW_PANE` — all while a labelless pane self-labels by its launch-dir basename (icon-aware). The SCEN-04 launch≡new equivalence holds for the new keys.

## What Was Built

**Task 1 — schema + grammar (pure modules):**
- `cli/lib/scene.lua` `parse_pane_spec`: `icon` joins the known-key branch (carried RAW as a name or literal glyph); the unknown-key error string now lists `icon`.
- `cli/lib/recipe.lua` `pane_table_to_spec`: emits an `icon=` segment (mirroring the `color=` append) and includes `p.icon` in the extra-field guards, so a styled shell pane (`cmd=shell, color=…, icon=…`) keeps its icon instead of collapsing to the bare `shell` fast path.
- `cli/lib/recipe.lua` `recipe_to_args`: carries tab-level `icon` and `follow_pane_color` (default OFF → nil when absent) beside `color`/`title`/`cwd`.
- Both modules stay PURE (purity grep = 0: no `io`/`os`/`wezterm` in code).

**Task 2 — scene-command emit (IO shell):**
- Extracted the Phase B per-pane escape construction into a PURE `M.build_pane_escapes(spec_parsed, opts)` helper. The live loop now calls it and octal-renders the result into the same self-erasing `printf` line (no standalone scrollback line; T-06.2-08 base64 fold-in preserved).
- Per-pane `WEZTERM_TAB_ICON` via the shared `titlelib.resolve_icon` (D-03).
- Per-pane color accent → `WEZTERM_PANE_COLOR`, split from the tab's own `WEZTERM_TAB_COLOR` (which pane 1 still carries) (D-07).
- `follow_pane_color` → the LOCKED `WEZTERM_TAB_FOLLOW_PANE = "1"` carrier on pane 1; nothing when unset (D-09 default OFF).
- Empty-title pane self-labels by `basename(launch_dir)` via the shared `titlelib.fallback_title`, icon-aware (`💚 myrepo`) when the pane has an icon (D-12/D-13); an explicit title and the `{cwd}` token are unchanged (D-11).
