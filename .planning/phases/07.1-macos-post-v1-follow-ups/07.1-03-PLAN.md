## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07.1-06 | Tampering (MITM / tampered asset) | downloaded `wez-macos-aarch64` | mitigate | The script verifies `.sha256` via `shasum -a 256` BEFORE `chmod +x`/run (build.sh idiom, RESEARCH §V6); exit non-zero on mismatch — never run an unverified binary |
| T-07.1-07 | Tampering (quarantine bypass) | `com.apple.quarantine` xattr | accept | The check OBSERVES quarantine (`xattr -p`) and documents the user-side fallback; it does NOT strip it (D-07). No installer mutation |
| T-07.1-08 | Spoofing (signature trust) | ad-hoc codesign | accept | Evidence is `codesign --verify` + the binary running, NOT `spctl` (ad-hoc always fails spctl — Pitfall 1); the doc states spctl rejection is expected, not a failure |
| T-07.1-09 | Elevation of Privilege | self-check execution | mitigate | Sudo-free, user-path only, scratch `mktemp -d` with trap cleanup; no system path / no hdiutil / no sudo (asserted by the Task-1 grep) |
| T-07.1-SC | Tampering | npm/pip/cargo installs | accept | No package-manager installs in this plan (script + docs only) — no supply-chain surface |

All threats are mitigate/accept; none `high`.
</threat_model>
