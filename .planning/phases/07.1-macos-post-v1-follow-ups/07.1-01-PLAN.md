<objective>
Make `wez scene` work out-of-box on a clean macOS install by mirroring `install_linux`'s
`ln -sfn` symlink block inside `install_macos`, so the bundled WezTerm CLI
(`~/Applications/WezTerm.app/Contents/MacOS/wezterm`) is resolvable by name on the user PATH
(`~/.local/bin/wezterm`). This closes macOS deviation #6 / follow-up A-4 (D-01/D-02).

Purpose: `wez scene new` and `wez scene launch <name>` shell out to `wezterm` by name. The
macOS `.app` bundle keeps the CLI at `Contents/MacOS/wezterm` and never exports it, so a clean
macOS install fails `error: mux returned a non-numeric pane id`. Linux already symlinks
`wezterm` onto PATH; this restores Linux↔macOS symmetry with the smallest correct change.
Output: a one-block addition to `install_macos` + a RED-first TEXT regression in the existing
macOS bootstrap test. Closes deviation #6 / A-4 (the SCEN traceability footers, not a new
requirement ID); contributes to INST-08 macOS verification.
</objective>
