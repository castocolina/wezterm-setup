## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| CLI args -> scene.lua | User-supplied `--layout`, `--pane '<spec>'`, `--color`, `--title` strings cross into the orchestration layer |
| scene.lua -> wezterm cli (shell-out) | Pane/tab IDs and user strings (commands, titles, colors) are interpolated into `os.execute`/`io.popen` command lines |
| wezterm cli list --format json -> scene.lua | JSON output is parsed and its `pane_id`/`tab_id` fields feed directly into subsequent shell-outs (split-pane --pane-id, set-tab-title --tab-id, activate-pane --pane-id) |
| scene.lua -> pane's shell (send-text) | OSC styling escapes + the user's startup command are written into the target pane's stdin stream |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | `wezterm cli list --format json` -> pane_id/tab_id used in split-pane/set-tab-title/activate-pane shell-outs | mitigate | Every pane_id/tab_id read from JSON output (or from `wezterm cli spawn`/`split-pane` stdout) is passed through `scenelib.validate_pane_id`/`validate_tab_id` (04-01, int-only) before being concatenated into any `os.execute`/`io.popen` command string.
