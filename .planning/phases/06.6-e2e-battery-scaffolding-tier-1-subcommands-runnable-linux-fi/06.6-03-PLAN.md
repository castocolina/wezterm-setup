<objective>
Build the emitted-OSC-byte well-formedness Tier 1 test: capture the stdout of `wez pane/tab
color|title|icon` (+ reset/clear) and assert the bytes match what the REAL emitter builds for
the same input — OSC-11 (`ESC ]11; hex ESC \`), OSC-111 reset (BEL), and OSC-1337 SetUserVar
(base64 value, BEL terminator). Two sources of truth feed the expected value: cli/lib/color.lua
builds the OSC FRAME (build_osc11/build_reset_osc11/build_osc1337/_base64), and cli/lib/title.lua
M.resolve_icon resolves the icon name->glyph (color.lua has no icon map). The byte contract is
made the SAME single source of truth those modules already are.

Purpose: user-vars reach the terminal as PROGRAM OUTPUT (the subcommand's own stdout) — the
exact stdout mechanism the reuse-pane scene styling (06.7) depends on. Getting the byte
contract right here de-risks 06.7.

Output: tests/e2e/tier1/osc_bytes_e2e_test.lua — green under `make e2e`.
</objective>
