### `tests/e2e/lib/harness.lua` (utility — shared TAP-ish helpers)

**Analog:** `tests/integration/keys_integration_test.lua` lines 56-98; `tests/cli/seed_scenes_test.lua` 105-109

Every existing test file re-declares the SAME `check`/`run_capture` block (the integration
file's own header at line 54 says "tiny harness (copied from scene_cwd_integration_test.lua)").
For e2e, hoist these into `tests/e2e/lib/harness.lua` once. Copy verbatim:

**`check` (the TAP-ish `ok`/`FAIL` emitter — line aggregator picks up these tokens):**
```lua
local passed, failed = 0, 0
local function check(label, ok, detail)
  if ok then
    passed = passed + 1
    print(string.format("  ok   - %s", label))
  else
    failed = failed + 1
    print(string.format("  FAIL - %s%s", label, detail and ("  (" .. tostring(detail) .. ")") or ""))
  end
end
```
Footer is always (keys_test.lua:191-192):
```lua
print(string.format("\n%d passed, %d failed", passed, failed))
os.exit(failed == 0 and 0 or 1)
```

**Subprocess capture (stdout + exit, and stdout+stderr) — keys_integration_test.lua 79-98:**
```lua
local function shquote(s) return "'" .. tostring(s):gsub("'", "'\\''") .. "'" end

local function run_capture(cmd)            -- stdout only
  local p = io.popen(cmd .. " 2>/dev/null", "r")
  if not p then return "", 1 end
  local out = p:read("*a") or ""
  local ok, _, code = p:close()
  return out, (code or (ok and 0 or 1))
end
local function run_capture_all(cmd)        -- stdout+stderr merged
  local p = io.popen(cmd .. " 2>&1", "r")
  ...
end
```
This `io.popen` + `p:close()` 3-return `(ok, _, code)` idiom is THE exit-code capture
pattern in the repo. Tier 1's "assert exit 0 / exit 1 / exit 2" all use it.

**`WEZ` binary resolver (keys_integration_test.lua 100-103) — copy exactly:**
```lua
local WEZ = os.getenv("WEZ_BIN")
if not WEZ or WEZ == "" then WEZ = "wez" end
```
Per CONTEXT "Dev launcher vs static binary": default `dist/wez` for local dev, `$WEZ_BIN`
override for CI's built luastatic binary.

**Scratch dir (seed_scenes_test.lua 105-109 / scene_launch_test.lua 51-56):**
```lua
local function scratch_dir(tag)
  local base = os.getenv("TMPDIR") or "/tmp"
  local dir = string.format("%s/wezsetup-%s-%d-%d", base, tag, os.time(), math.random(1, 1e6))
  assert(os.execute("mkdir -p '" .. dir .. "'"))
  return dir
end
```
Tier 1 `seed-scenes`/`install-state`/`uninstall` use this for the scratch `WEZTERM_SETUP_DIR`.

**`package.path` bootstrap header (every test, keys_test.lua 14-20):**
```lua
local this_dir = (arg and arg[0] or ""):match("^(.*)/[^/]-$") or "."
local repo_root = this_dir .. "/../.." -- tests/e2e/tier1 -> repo root (adjust depth)
package.path = table.concat({
  repo_root .. "/?.lua",
  repo_root .. "/cli/vendor/?.lua",
  package.path,
}, ";")
```
NOTE: e2e files under `tests/e2e/tier1/` are TWO levels below `tests/`, so `repo_root` is
`this_dir .. "/../../.."` (three `..`). Get the depth right per directory.

### `tests/e2e/lib/skip.lua` (utility — generalized self-skip gate)

**Analog:** `tests/integration/keys_integration_test.lua` lines 106-141

This is the pattern CONTEXT calls "self-skip must be loud and logged — never a silent pass,
never a hang." The integration file has TWO gates to generalize:

**Gate 1 — env opt-in flag (lines 106-112):**
```lua
if os.getenv("WEZTERM_INTEGRATION") ~= "1" then
  print("keys_integration_test: SKIP (WEZTERM_INTEGRATION != 1)")
  os.exit(0)
end
```
Generalize to a `skip.require_env(flag, label)` so 06.9 tiers plug in `WEZ_E2E_INPUT=1` /
`WEZ_E2E_VISUAL=1`. Tier 1 itself needs NO env flag (deterministic, always runs).

**Gate 2 — dependency-present predicate with LOUD logged skip (lines 121-134):**
```lua
local display = os.getenv("DISPLAY")
local has_display = display ~= nil and display ~= ""
local list_out, list_exit = run_capture("wezterm cli list --format json")
local mux_reachable = list_exit == 0 and list_out:find("pane_id", 1, true) ~= nil

if not (has_display and mux_reachable) then
  print(string.format(
    "keys_integration_test: SKIPPED (host not display-capable: DISPLAY=%s, mux_reachable=%s)",
    has_display and tostring(display) or "<unset>", tostring(mux_reachable)))
  os.exit(0)
end
```
KEY CONTRACT to preserve (header lines 30-39): on a host that DOES have the dependency, a
skip is a FAILURE — print a `LIVE-ASSERTED` marker (line 140-141) when running for real, and
distinguish a whole-tier skip from a per-assertion `soft_skip` (lines 71-73):
```lua
local function soft_skip(label, why)
  print(string.format("  skip - %s  (%s)", label, tostring(why)))
end
```
Build `skip.lua` to return `{require_env=…, require_tool=…, soft_skip=…}` exposing this exact
loud-skip + LIVE-ASSERTED-marker behavior. Tier 1 needs no dependency gate; the gate exists
here so 06.7-06.9 tiers plug into it.

### `tests/e2e/tier1/*_e2e_test.lua` (test — per-subcommand exit + output contracts)

**Analog:** `tests/integration/keys_integration_test.lua` (driver) + `tests/cli/scene_launch_test.lua` (edge-case exit codes)

**Exit-code + output-shape assertion (keys_integration_test.lua 144-147):**
```lua
local keys_out, keys_exit = run_capture_all(shquote(WEZ) .. " keys")
check("`wez keys` ran (exit 0)", keys_exit == 0,
  "exit=" .. tostring(keys_exit) .. " out=" .. tostring((keys_out or ""):sub(1, 200)))
```
Apply per A.1 row: `version`→exit 0 + version string; `doctor`→exit 0 + gate lines;
`completions bash|zsh`→exit 0 + non-empty.

**Valid-JSON assertion via vendored dkjson + optional jq cross-check (lines 256-276):**
```lua
local ok_dk, dkjson = pcall(require, "dkjson")
local decoded = dkjson.decode(json_out)
check("`--json` is valid JSON", type(decoded) == "table")
-- cross-check with jq only if present:
local _, jq_present = run_capture("command -v jq")
if jq_present == 0 then
  local _, jq_exit = run_capture("printf %s " .. shquote(json_out) .. " | jq . > /dev/null")
  check("`wez keys --json` is jq-valid", jq_exit == 0)
end
```
Use for `wez keys --json`.

**Edge-case exit codes via child `lua5.4 -e` with env set (scene_launch_test.lua 17-18, 58-70):**
lua5.4 has NO `os.setenv`, so env-dependent paths (`WEZTERM_SETUP_DIR`) run in a CHILD
process. This is the portable pattern for the unknown-scene (exit 1), empty-recipes (exit 2),
and path-traversal (exit 1) edge cases:
```lua
local function run_launch_child(setup, name)
  local namelit = name == nil and "nil" or string.format("%q", name)
  local body = string.format(
    "package.path=%q..package.path;"
      .. "local s=require('cli.commands.scene');"
      .. "os.exit(s.run_launch({name=%s}))",
    repo_root .. "/?.lua;" .. repo_root .. "/cli/vendor/?.lua;", namelit)
  -- ... invoke `WEZTERM_SETUP_DIR=setup lua5.4 -e body`, return (exit, output)
end
```
For e2e prefer driving the real `wez` binary with the env prefixed:
`run_capture_all("WEZTERM_SETUP_DIR=" .. shquote(dir) .. " " .. shquote(WEZ) .. " scene launch ...")`.

### `tests/e2e/tier1/osc_bytes_e2e_test.lua` (test — OSC byte well-formedness)

**Analog (driver):** `keys_integration_test.lua` `run_capture` + the `find("\27[", 1, true)` byte-scan (lines 252-253)
**Analog (byte CONTRACT — source of truth):** `cli/lib/color.lua` lines 83-123

`wez pane/tab color|title|icon` write OSC to their OWN stdout (CONTEXT "OSC delivery model").
Capture that stdout and assert it matches what `color.lua` builds. The exact byte shapes:

**OSC 11 set background (color.lua:84-86) — ESC-`]11;`-hex-ST:**
```lua
function M.build_osc11(hex) return "\27]11;" .. hex .. "\27\\" end
```
Assert: `out:find("\27]11;", 1, true)` present AND ST-terminated `"\27\\"`.

**OSC 111 reset (color.lua:89-91) — BEL-terminated:**
```lua
function M.build_reset_osc11() return "\27]111\7" end
```

**OSC 1337 SetUserVar, base64 value (color.lua:110-112) — used for icon/title user-vars:**
```lua
function M.build_osc1337(varname, value)
  return "\27]1337;SetUserVar=" .. varname .. "=" .. base64_encode(value or "") .. "\7"
end
```
Assert prefix `"\27]1337;SetUserVar="`, BEL `"\7"` terminator, and that the value segment is
valid base64. `M._base64` is exposed for tests (line 107) — `require("cli.lib.color")` and
recompute the expected base64 to compare against captured bytes.

**Octal printf form (color.lua:119-123) — the `\nnn` send-text path:** if the subcommand emits
the printf-octal variant, assert every byte rendered as `\%03o`:
```lua
:gsub(".", function(c) return string.format("\\%03o", string.byte(c)) end)
```

Pattern: `require` `cli.lib.color`, build the EXPECTED bytes for the same input, capture the
subcommand's stdout, and `check(captured:find(expected, 1, true) ~= nil)`. This makes the byte
contract the SAME single source of truth `color.lua` already is.

### `tools/run-e2e.sh` (tool — battery orchestrator)

**Analog:** `tools/run-tests.sh` (entire file — copy its structure)

Mirror its skeleton exactly:
- **Repo-root resolution from script location (lines 22-26):**
```bash
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
REPO_ROOT="$(cd "${SCRIPT_DIR}/.." && pwd)"
cd "${REPO_ROOT}" || exit 1
```
- **`LUA_BIN` resolution + missing-binary guard (lines 28-32).**
- **Discover → dispatch → per-file PASS/FAIL → aggregate FAILED → exit non-zero (lines 123-139):**
```bash
for f in "${FILES[@]}"; do
  if "${LUA_BIN}" "$f"; then printf 'PASS  %s\n' "$f"
  else printf 'FAIL  %s\n' "$f"; FAILED=$((FAILED + 1)); fi
done
[ "$FAILED" -ne 0 ] && { echo "run-e2e: ${FAILED} file(s) failed"; exit 1; }
```
- **`set -u`** (line 20), never `set -e` for the loop (matches run-tests.sh).

**BASH-3.2 PORTABILITY LANDMINE — DO NOT COPY run-tests.sh's discovery verbatim.**
`tools/run-tests.sh` uses `mapfile -t ... < <(...)` at lines 50, 76, 95 — `mapfile`/`readarray`
is **bash-4 only** and will break on macOS bash 3.2. CONTEXT explicitly bans it. `run-e2e.sh`
MUST collect files with the bash-3.2-safe `while read` + array-append idiom run-tests.sh
ALSO uses elsewhere (lines 70-76, 92-95):
```bash
FILES=()
while IFS= read -r f; do
  [ -f "$f" ] && FILES+=("$f")
done < <(find tests/e2e -type f -name '*_e2e_test.lua' | sort)
```
Also forbidden (CONTEXT): associative arrays (`declare -A`) and `${var^^}` uppercasing — use
`tr '[:upper:]' '[:lower:]'` like `platform.sh` line 25 if case-folding is needed. The
`while...done < <(find | sort)` process-substitution idiom IS bash-3.2-safe and already used here.

## Shared Patterns

### TAP-ish `ok`/`FAIL` aggregation contract
**Source:** `tests/cli/keys_test.lua` 22-31, 191-192; `tools/run-tests.sh` 123-131
**Apply to:** every Tier 1 test file + `run-e2e.sh`
Each Lua test prints `  ok   - <label>` / `  FAIL - <label>` lines and exits `0` iff
`failed == 0`. The orchestrator keys ONLY off the per-file process exit code (PASS/FAIL),
so results aggregate through `run-e2e.sh` exactly like `run-tests.sh`.

### Subprocess exit-code capture
**Source:** `tests/integration/keys_integration_test.lua` 79-98
**Apply to:** all Tier 1 tests
`io.popen(cmd .. " 2>&1", "r")` then `local ok, _, code = p:close()` → exit code. This is the
ONLY exit-code capture mechanism in the repo; reuse it, do not invent another.

### Loud, logged self-skip (never silent, never hang)
**Source:** `tests/integration/keys_integration_test.lua` 106-141
**Apply to:** the self-skip gate; later tiers (06.7-06.9) plug in
Print an explicit `SKIPPED (reason=…)` line and `os.exit(0)`; on a capable host a skip is a
FAILURE and a `LIVE-ASSERTED` marker must print. `soft_skip` (per-assertion) ≠ whole-tier skip.

### bash-3.2-safe orchestration
**Source:** `tools/lib/platform.sh` (entire — `case`/`tr`, no bash-4); `run-tests.sh` 70-95 (`while read` loops)
**Apply to:** `run-e2e.sh`, `e2e-setup`
NO `mapfile`/`readarray` (run-tests.sh line 50 violates this — do NOT copy that line), NO
`declare -A`, NO `${var^^}`. Use `while IFS= read -r ... done < <(find | sort)` for discovery
and `tr '[:upper:]' '[:lower:]'` for case folding. `shellcheck -x` + `bash -n` are advisory
gates run-tests.sh already applies (lines 97-118) — keep `run-e2e.sh` clean under both.

### Subcommand enumeration (single source of truth)
**Source:** `cli/spec.lua` 39-70 (`CATEGORIES` + `SUBCOMMANDS` closed allow-list)
**Apply to:** Tier 1 enumeration
The canonical `wez` surface is `SUBCOMMANDS`: `version, doctor, keys, install-state,
uninstall-state, uninstall, seed-scenes, update, completions, pane, tab, scene` (+ hidden
`__complete`). `M.VERSION = "0.1.0"` (line 35) is the version string `wez version` must print.
Enumerate Tier 1 against this list so a newly added subcommand is detectable as untested.
