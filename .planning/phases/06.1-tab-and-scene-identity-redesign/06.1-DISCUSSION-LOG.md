## Tab color across panes

### Q1 — Which color does the tab use when panes disagree?

| Option | Description | Selected |
|--------|-------------|----------|
| Active pane wins | Tab takes the focused pane's color; dynamic, reads `tab.active_pane` | ✓ |
| First/anchor pane wins | Stable anchor pane carries tab color; never shifts on focus | |
| Explicit tab color overrides | A designated carrier pane always wins; closest to today's split | |

**User's choice:** Active pane wins → **D-02**.

## Recipe cwd/focus/size shape

### Q1 — How is `focus` declared?

| Option | Description | Selected |
|--------|-------------|----------|
| Per-pane boolean `focus=true` | First marked wins; validate >1; mirrors color/title | ✓ |
| Tab-level `focus = <index>` | Single top-level index; couples to pane order | |

**User's choice:** Per-pane boolean → **D-05**.

### Q2 — What does `size` mean?

| Option | Description | Selected |
|--------|-------------|----------|
| Per-pane split fraction 0..1 | `size = 0.3` = 30% | |
| Percent integer 1..100 | `size = 30` = 30%; integer ergonomics | ✓ |

**User's choice:** Percent integer 1..100 → **D-06**.

### Q3 — Default cwd when a pane omits it?

| Option | Description | Selected |
|--------|-------------|----------|
| Inherit launch dir | Spawn dir of `scene launch`/`new`; `.` grammar consistent | ✓ |
| Inherit from tab-level cwd | Cascade a top-level `cwd` to panes | |

**User's choice:** Inherit launch dir → **D-07**.
**Notes:** *"...la funcionalidad actual es que si voy a HOME/git/personal/myproject y levanto la
escena en cualquier dir, los panes deberían heredar esa ruta. A propósito entiendo que para llegar
allí se ejecuta `cd ..ruta` pero un requerimiento claro para ello es que el pane debería quedar
limpio y eso no está pasando."* → **D-08 clean-pane requirement**: apply cwd at spawn time
(native spawn `cwd`), no visible `cd` line. Current spawn-then-`cd` clutter is the bug.

## wezterm.lua migration safety

### Q1 — How aggressive should migration be?

| Option | Description | Selected |
|--------|-------------|----------|
| Detect + instruct, never auto-edit | Doctor detects + tells user; installer backup | (basis) |
| Auto-rewrite with backup | Command rewrites user's file in place | |
| Offer auto-fix, default to manual | Detect+instruct + opt-in `--fix` | |

**User's choice (free text):** *"Haz lo mejor que se pueda, entiende esto no es un producto masivo,
yo bien podría borrar todo el dir de config custom y volver a instalar. A propósito sería bueno
tener un `wez --uninstall` que haga eso por si no se descargó el repo sino solo el binary."*
→ **D-10** best-effort detect + instruct; clean reinstall is an acceptable reset; opt-in `--fix`
allowed but not required. **`wez uninstall` → Deferred Ideas** (new capability).

### Q2 — doctor shadow-detection severity?

| Option | Description | Selected |
|--------|-------------|----------|
| Advisory probe (informational) | Reported, exit stays 0 | |
| Core GATE (non-zero exit) | Fails doctor loudly alongside GATE 1–4 | ✓ |

**User's choice:** Core GATE → **D-11**.
