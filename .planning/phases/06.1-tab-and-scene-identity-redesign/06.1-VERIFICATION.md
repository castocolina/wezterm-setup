# Phase 06.1: Tab and Scene Identity Redesign Verification Report

**Phase Goal:** Decouple tab COLOR from tab TITLE everywhere and remove the legacy
`"<color>:<title>"` encoding (a pre-roadmap scripting shortcut), so tabs use the same clean
two-user-var model panes already use — then extend the scene recipe model with the attributes
daily use needs. This is the last cleanup before the macOS pass, so macOS verifies the
redesigned behavior.
