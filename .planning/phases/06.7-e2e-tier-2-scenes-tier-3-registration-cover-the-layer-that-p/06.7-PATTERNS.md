of the existing `tests/e2e/tier1/*_e2e_test.lua` files and reuses the 06.6 scaffold
verbatim. The dominant directive across ALL files: **copy the tier1 idioms, do not
invent new ones.**

### `tests/e2e/tier2/*_e2e_test.lua` (live-mux scene tests)

**Primary analog:** `tests/e2e/tier1/scene_edge_e2e_test.lua` (scene domain, child-process exit capture)
**Secondary analog:** `tests/e2e/tier1/install_cycle_e2e_test.lua` (scratch-dir isolation, ABS path resolution, reachability-gated live smoke)
**Skip-gate analog:** `tests/e2e/tier1/keys_siblings_e2e_test.lua` (the `skip.require_tool` LIVE-ASSERTED / SKIPPED gate)

**Header / package.path bootstrap** — copy verbatim from `scene_edge_e2e_test.lua` lines 30-43; tier2 is also three `..` from repo root, and ALSO needs the `tests/e2e/?.lua` entry (from `keys_siblings_e2e_test.lua` line 37) so `require("platform")` resolves:
```lua
local this_dir = (arg and arg[0] or ""):match("^(.*)/[^/]-$") or "."
local repo_root = this_dir .. "/../../.." -- tests/e2e/tier2 -> repo root (three ..)
package.path = table.concat({
  repo_root .. "/?.lua",
  repo_root .. "/tests/e2e/lib/?.lua",
  repo_root .. "/tests/e2e/?.lua",        -- platform.lua (D-06 chord-family table)
  repo_root .. "/cli/vendor/?.lua",
  package.path,
}, ";")
local h = require("harness")
local skip = require("skip")
```

**Mux skip-gate (D-03)** — the loud, un-hideable gate from `skip.lua` 51-59, fired exactly as `keys_siblings_e2e_test.lua` 92-95 fires it. Probe = is `wezterm` (and `wezterm-mux-server`) runnable:
```lua
-- probe_fn returns truthy only when the live mux dependency is present.
skip.require_tool(
  function()
    local p = io.popen("command -v wezterm-mux-server 2>/dev/null"); if not p then return false end
    local out = p:read("*l") or ""; p:close(); return out ~= ""
  end,
  "tier2 scene live-mux contract",
  "wezterm-mux-server not on PATH (headless mux unavailable)")
-- LIVE-ASSERTED marker printed here => a skipped pass on a capable host is impossible to hide.
```
Note `require_tool` calls `os.exit(0)` on the skip path; if any always-run cross-platform
checks precede it, emit `h.footer()` FIRST and gate after (the `keys_siblings_e2e_test.lua`
88-95 `xplat_rc` idiom).

**Fresh-mux-per-case spin/teardown (D-03)** — no existing analog for the headless `wezterm-mux-server`
incantation (Claude's discretion). Reuse the **scratch-dir isolation** idiom from
`harness.lua` `scratch_dir` (lines 73-78) for the per-case mux socket/state dir, and the
`rmrf` helper pattern (`install_cycle_e2e_test.lua` 78-80) for deterministic teardown:
```lua
local function rmrf(dir) os.execute("rm -rf " .. shquote(dir)) end
local muxdir = h.scratch_dir("e2e-tier2-mux")  -- unique per run; never the user's session
-- ... spin `wezterm-mux-server` against muxdir, run case, then rmrf(muxdir)
```

**Subprocess capture + exit code** — the ONLY exit-capture idiom in the repo, already
hoisted into `harness.lua` 51-68 (`run_capture` / `run_capture_all`). Use them; do NOT
re-roll `io.popen` + `p:close()`.

**Pane-count + cwd + user-var assertions (the Tier 2 payload)** — drive `wezterm cli list --format json`
exactly as the launcher under test does. The launcher's own topology read is the reference shape
(`cli/commands/scene.lua` `read_topology` 92-111): each entry carries `{pane_id, tab_id}` and is
int-validated via `scenelib.validate_pane_id`. For Tier 2, also read the per-pane `cwd` field
from `cli list` (D-08) and the `user_vars` (color/icon/title) WezTerm exposes per pane.
Recipe pane-count truth (assert against these): **ai=2, dev=3, docker=3** (`scenes/{ai,dev,docker}.toml`).

**Mode-selection assertion (reuse vs new-tab)** — do NOT reimplement; assert the PURE decision from
`cli/lib/scene.lua` `decide_materialization` 332-353 (single-pane current tab → `reuse`; ≥2 → `new-tab`)
and `plan_splits` 61-132. Tier 2 sets up the precondition (single-pane tab vs multi-pane tab) and
asserts the materialized result matches.

**No-escape-leak check (D-05)** — the contract `osc_bytes_e2e_test.lua` already proved at the byte
level (OSC reaches the terminal as program output, NOT echoed shell input). Tier 2 reads
`wezterm cli get-text` and asserts the styling bytes were *interpreted*, not echoed. The leak
patterns to reject (D-05): literal `printf '` text, raw octal `\nnn` runs, `quote>` continuation
prompts. The emitter being guarded is `cli/commands/scene.lua` 478-493 (the self-erasing octal
`printf` line):
```lua
local CLEAR_SCROLLBACK_AND_VIEWPORT = "\27[2J\27[3J\27[H"
-- octal-render every byte so the typed line is pure printable ASCII (no raw ESC for readline)
local octal = table.concat(escapes):gsub(".", function(c) return string.format("\\%03o", string.byte(c)) end)
payload[#payload + 1] = "printf '" .. octal .. "'\n"
```

**No-hang / responsiveness probe (D-04)** — marker-echo, not a fixed sleep. Send a unique UUID into a
pane via `wezterm cli send-text` (same send-text path scene.lua 491-493 uses) and poll
`wezterm cli get-text` until it echoes within a bounded timeout. Reuse the **bounded reachability-probe
pattern** from `install_cycle_e2e_test.lua` 293-313 (curl `--max-time 3` → branch → `soft_skip` loud on
failure) as the shape for "poll-with-timeout, loud on miss".

**Deterministic state-polling + bounded retries (D-02)** — no existing analog (Claude's discretion on N
and timeouts). Build the poll loop on `run_capture` + a bounded counter; log EVERY retry loudly
(`print("  retry - ...")`) so an intermittent real hang stays visible, never masked.

**Footer** — every file ends identically: `os.exit(h.footer())` (`scene_edge_e2e_test.lua` 121).

### `tools/run-e2e-prove.sh` — break-harness (D-09)

**Analog:** `tools/run-e2e.sh` (structure + header conventions). New script; carries over EVERY
convention from that file's header (lines 17-25):
- `set -u`; resolve `REPO_ROOT` from `BASH_SOURCE` (lines 31-33).
- **bash-3.2-safe** (macOS ships bash 3.2): NO `mapfile`/`readarray`, NO associative arrays, NO
  `${var^^}`; use the `while IFS= read -r` + array-append idiom (lines 66-69) and `tr` for case-folding.
- Clean under `bash -n` and `shellcheck -x`.

**Behavior (per-bug, not combined — D-09):** for each known regression (scene escape-leak; dead new-tab
binding), inject it ONE at a time, run the battery (`./tools/run-e2e.sh`), assert it **FAILS** (non-zero),
then revert. **Must leave the tree clean on exit even on failure** — use a `trap '... revert' EXIT` so an
abort still restores. Reverting is the inverse of the inject (git-stash/checkout of the touched file, or a
sed-patch + sed-unpatch pair); the injected targets are `cli/commands/scene.lua` (the octal `printf`
emitter 478-493 → escape-leak) and `config/wezterm-setup/keybindings.lua` (the SpawnTab row line 85 →
dead new-tab binding).

## Shared Patterns

### TAP-ish harness (every test file)
**Source:** `tests/e2e/lib/harness.lua` — `check` (95-103), `footer` (109-114), `run_capture` /
`run_capture_all` (51-68), `shquote` (46-48), `scratch_dir` (73-78), `WEZ` (84-85).
**Apply to:** all tier2 + tier3 files. Consume at module level (`local h = require("harness")`); end with
`os.exit(h.footer())`. Never copy-paste the io.popen idiom — it lives here once.

### Loud self-skip contract (mux-bound + show-keys-bound tiers)
**Source:** `tests/e2e/lib/skip.lua` — `require_tool` (51-59, whole-tier dependency: absent → loud
`SKIPPED (reason=...)` + exit 0; present → `LIVE-ASSERTED` marker + return), `soft_skip` (66-68,
per-assertion graceful skip, no exit).
**Apply to:** every tier2 file (mux gate) and the tier3 file (wezterm gate). A skip is ALWAYS printed and
explained — never silent, never a hang. The `LIVE-ASSERTED` marker makes a hollow pass on a capable host
impossible to hide.

### Platform parity table (cross-OS deltas)
**Source:** `tests/e2e/platform.lua` — `platform_os()` (32-42), `expectations` rows (64-112).
**Apply to:** tier3 (D-06 chord families) and any tier2 macOS-specific expectation. A per-OS difference is
an explicitly-named row, never an accidental assumption. macOS-only assertions are skip-gated here (live
verification deferred to Phase 7).

### Scratch isolation (never touch the user's real session/config)
**Source:** `harness.lua` `scratch_dir` (73-78, unique per run via `os.time`+random); `rmrf` helper
(`install_cycle_e2e_test.lua` 78-80).
**Apply to:** every tier2 case (per-case fresh mux dir) and any FS-touching setup. The user's real
`~/.config/wezterm` and live WezTerm session are NEVER touched.

### bash-3.2-safe orchestration (every shell-out + new script)
**Source:** `tools/run-e2e.sh` header (17-25) + discovery idiom (66-69).
**Apply to:** `tools/run-e2e-prove.sh`. No bash-4 constructs; `while read` + array-append; `tr` for
case-folding; clean under `bash -n` / `shellcheck -x`.

### Auto-discovery (no orchestrator edit needed)
**Source:** `tools/run-e2e.sh` 63-74 — `find tests/e2e -type f -name '*_e2e_test.lua'`.
**Implication:** new `tier2/` and `tier3/` files are picked up automatically; `run-e2e.sh` needs **zero**
changes. `WEZ_BIN` defaults to `./dist/wez` locally (79-82); CI overrides it.
