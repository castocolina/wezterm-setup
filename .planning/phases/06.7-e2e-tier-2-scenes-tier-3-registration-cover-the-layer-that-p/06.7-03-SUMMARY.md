## Decisions Made
- **Families encoded as live-observed, not PRD-blanket (D-06):** calibrated each per-OS family set against the actual `wezterm show-keys --lua` effective table on this box (137 records, 0 dropped). This avoids spurious Mac<->Linux false-fails while still catching a silently-dropped binding.
- **LIVE_MATCH alias map:** `ClearScreenAndScrollback` is sugar resolved by `init.lua` (`resolve_action`, lines 63-64) to WezTerm-native `act.ClearScrollback`, so the live records carry "ClearScrollback". The curated contract keeps the keybindings.lua action-type name; the test bridges via a small alias table.
- **Path-neutral skip reason:** `skip.require_tool` prints the reason on BOTH the SKIPPED and LIVE-ASSERTED lines, so the reason names the dependency ("needs a runnable wezterm ...") rather than a skip-only phrasing.
