<domain>
## Phase Boundary

This phase covers the **running-application layer that produced the worst regressions** (PRD Phase 2) — the live mux behavior unit tests can't see.

**In scope (this phase = PRD Phase 2):**
- **Tier 2 — Scenes (live mux):** each recipe (`ai`/`dev`/`docker`) × **both launch modes** (reuse single-pane-tab AND new-tab) = 6 cases, each asserting:
  - **pane-count parity** with the recipe (ai=2, dev=3, docker=3),
  - **per-pane cwd == launch dir** (D-08) via `wezterm cli list`,
  - **user-vars set** (color/icon/title on styled panes),
  - **no escape-char leak** in `wezterm cli get-text`,
  - **responsiveness / no-hang probe**,
  - **deterministic cleanup** (zero residue).
- **Tier 3 — Registration (deterministic):** parse `wezterm show-keys --lua` and assert, per curated action, the expected chord families are registered (catches a silently-dropped binding like the dead new-tab chord).
- **Permanent regression-proof harness** demonstrating the battery catches a reintroduced scene-leak AND a dead new-tab binding.

**Out of scope (later phases — do NOT build here):**
- Linux CI gate / GitHub Actions wiring → **06.8** (this phase makes Tier 2 + Tier 3-registration *gate-ready*; 06.8 wires them in).
- Tier 3 **firing** (OS input injection → mux-effect) + Tier 4 visuals → **06.9**.
- macOS on-hardware verification → Phase 7 (macOS-specific expectations are skip-gated here, per the 06.6 OS-gating pattern).
- New scene/keybinding *capabilities* — this phase only **tests** existing behavior.

<decisions>
## Implementation Decisions

Carried forward from 06.6 (locked, do not re-litigate): assertions in **Lua**; any shell-out is **bash-3.2-safe** (no mapfile/readarray/assoc-arrays); self-skip is **loud, never silent, never a hang**; TAP-ish `ok`/`FAIL` aggregated by `tools/run-e2e.sh`; battery targets `dist/wez`; OSC reaches the terminal as **program output** (proven in Tier 1). The 06.6 scaffold APIs (`harness.lua`, `skip.lua`, `platform.lua`) are the building blocks.

### Tier 2 — CI posture & flake control
- **D-01:** Tier 2 is **gate-bound** — it must be trustworthy enough for 06.8 to block PRs on it (T1 + T2 + T3-registration are the CI-gating deterministic tiers). It is NOT local-only.
- **D-02:** Flake-control = **deterministic state-polling + bounded retries**. Poll `wezterm cli list` / `get-text` until the expected state (pane count, cwd, marker echo) within a bounded timeout — prefer this over fixed `sleep`s. A **bounded retry** (re-run a failed case up to a small N) is the safety net on top. *(Planner: keep retries small and log every retry loudly so an intermittent real hang is visible, not silently masked.)*

### Tier 2 — Isolation, cleanup & reliability mechanics
- **D-03:** **Fresh `wezterm-mux-server` per case.** Each of the 6 cases spins its own dedicated headless mux-server and tears it down — maximum isolation, zero cross-case residue, no shared-state flake. Skip-gate loudly (`skip.require_tool`) when wezterm / mux-server is unavailable. *(This pairs with D-02's retry net for a belt-and-braces reliability posture. Cost: 6 spin/teardown cycles — acceptable for correctness.)*
- **D-04:** **No-hang / responsiveness probe** = send a **unique UUID marker** into a pane and assert it echoes back within a **bounded timeout**; absence = hang = FAIL. *(Default — planner may tune the timeout to tolerate shell-startup latency, but the mechanism is marker-echo, not a fixed sleep.)*
- **D-05:** **"Escape-char leak"** = literal `printf '` text, raw octal `\nnn` runs, or `quote>` continuation prompts appearing in `wezterm cli get-text` output. *(Default leak-pattern set; planner refines the exact regex/byte patterns — this is the same OSC-as-program-output contract Tier 1 proved.)*

### Tier 3 — Registration design
- **D-06:** Per-action chord-family assertion uses **platform-expected families sourced from `platform.lua`** — assert each curated action has the chord families *actually expected on the running platform* (Linux requires its bound families; macOS may additionally require Cmd). Avoids spurious cross-platform fails while still catching a dropped binding. Do NOT hard-require both Cmd+Ctrl on every platform (would false-fail on Linux where SUPER/Cmd isn't used for these actions and the WM can grab Super).
- **D-07:** **Curated action list = the PRD's verbatim list, cross-checked against `config/wezterm-setup/keybindings.lua`.** If the PRD list and the live keytable disagree, surface it (a disagreement is itself a finding), don't silently drop.
- **D-08:** Tier 3 parses `wezterm show-keys --lua` via the existing **string-parse-only** path (`cli/lib/showkeys.lua`, never eval/load); modal `key_tables` stay excluded (D-13 from 06.5). *(Whether to additionally contract-test a `show-keys --json` shape is Claude's discretion — fold into Tier 1 if cheap, otherwise skip.)*

### Regression-proof harness
- **D-09:** Ship a **permanent, per-bug "break harness"** (e.g. a `make e2e-prove` target / documented script) that injects each known regression **one at a time** (scene escape-leak; dead new-tab binding), runs the battery, asserts it **FAILS**, then reverts — re-runnable living proof the battery has teeth. Per-bug (not combined) so each check is shown to fail independently. Must leave the tree clean on exit (revert even on failure).

### Claude's Discretion (planner/executor choose)
- Exact directory layout under `tests/e2e/tier2/` + `tests/e2e/tier3/` (mirror the `tier1/` convention).
- The precise mux spin-up/teardown incantation and headless flags for `wezterm-mux-server`.
- Exact retry count N and per-step poll timeouts (keep small + logged).
- Exact leak regex/byte patterns and the user-var read API (`wezterm cli list` fields vs parsing captured OSC).
- Whether the break-harness is a Makefile target, a `tools/` script, or both; commit grouping (group by logical unit per project commit discipline).
- Whether `show-keys --json` gets a Tier 1 shape contract.

</decisions>

<specifics>
## Specific Ideas

- **Belt-and-braces reliability:** D-03 (fresh mux per case) + D-02 (polling + bounded retries) were chosen together — isolation removes cross-case state, retries absorb residual transient noise, polling removes sleep-based flake. The CI gate (06.8) depends on this combination holding.
- **Per-bug proof, not combined:** the break harness (D-09) injects the scene-leak and the dead-new-tab regressions separately so each tier's teeth are demonstrated independently — directly mirrors the two real regression classes that motivated the battery.
- **Disagreement is a finding:** for Tier 3 (D-07), if the PRD curated list and `keybindings.lua` diverge, the test surfaces it rather than silently trusting either source.

</specifics>
