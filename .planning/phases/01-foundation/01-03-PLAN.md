<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user config object -> apply() | `apply(config)` mutates the user's live config table; it must add only and never strip user-set fields (non-destructive contract) |
| shell rc -> OSC 7 emitter | the shipped shell integration runs in the user's interactive shell on every prompt; it must not break the prompt or leak the escape into output incorrectly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Tampering | `apply(config)` overwriting user settings | mitigate | `apply` only assigns the specific fields it owns (keys, key_map_preference, cwd) and merges into (does not reassign) the user's `keys` list; the apply_test asserts the returned table is the same object it received |
| T-03-02 | Information Disclosure | OSC 7 emitter writing escapes to a non-terminal | mitigate | Emit OSC 7 only when stdout is a TTY / inside an interactive shell prompt hook, so the escape never contaminates piped/redirected output |
| T-03-03 | Denial of Service | a broken prompt hook hanging the shell | mitigate | The OSC 7 hook is a single fast `printf`; guard against double-registration and avoid subshell forks in the hot path |
| T-03-SC | Tampering | no package-manager installs | accept | This plan ships only first-party Lua + shell files; no npm/pip/cargo install occurs, so no Package Legitimacy Gate applies |
</threat_model>
