## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner → GitHub Release | CI publishes the public download assets using `github.token` |
| Third-party Actions (`actions/checkout`, optional `action-gh-release`) → build env | External code runs in the release pipeline |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-03-01 | Tampering | compromised third-party Action | mitigate | Pin `actions/checkout` (and `softprops/action-gh-release` if used) to a tag or SHA (RESEARCH supply-chain row); never `@main` |
| T-06-03-02 | Tampering | wrong/failed-build asset shipped | mitigate | `ci-setup-toolchain.sh` fails the leg if `luastatic` is absent (no silent dev-launcher fallback); arm64 leg `codesign --verify` sanity-checks the signature before upload |
| T-06-03-03 | Elevation | over-broad workflow token | mitigate | `permissions: { contents: write }` only — least privilege for release upload; no other scopes granted |
| T-06-03-04 | Repudiation | unsigned arm64 asset won't run | mitigate | Ad-hoc `codesign --force --sign -` on the `macos-14` leg (Pattern 7); Gatekeeper/quarantine runtime is Phase 7 |
| T-06-03-SC | Tampering | luastatic (LuaRocks) install on runners | mitigate | luastatic is the project's locked build tool (D-02), `[ASSUMED]`; the real per-runner install + version capture in `ci-setup-toolchain.sh` IS the legitimacy gate (slopcheck does not cover LuaRocks). No npm/pip/cargo installs. No `[SLOP]`/`[SUS]` packages. |
